# EstoqMais — controle de compras

Aplicativo pessoal em português para pedidos, fornecedores, comparação de preços e relatórios.

## Acesso e salvamento

Acesse https://jotappe23.github.io/estoqmais/ e entre na sua conta online. Internet é obrigatória para entrar e salvar. Cada alteração só é concluída após a confirmação do servidor. Não há login offline ou sincronização de cópias locais.

Se o envio falhar, o formulário continua aberto. Tente novamente quando a internet voltar. Para um envio de resultado incerto, use Verificar envio antes de cadastrar novamente.

## Versão para PC

Baixe EstoqMais-PC.zip no site, extraia tudo e abra EstoqMais.html ou crie o atalho com Criar-atalho.vbs. A versão para PC também exige internet e usa a mesma conta. O download não contém registros pessoais.

## Recuperação e backup

Gerenciar permite exportar todos os meses e consultar as últimas dez versões online. Arquivos antigos já existentes no navegador são preservados para exportação manual, sem importação ou envio automático. O backup JSON contém referências aos anexos, não os arquivos em si.

Leia OTIMIZACAO-E-USO.txt para detalhes. A configuração Supabase existente é mantida.
